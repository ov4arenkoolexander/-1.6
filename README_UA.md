# Будівельник UA — версія 1.6

Офлайн Android-довідник українською мовою.

## Що є у версії 1.6
- Калькулятори геометричного об'єму бетону та теоретичної маси арматури.
- Довідкові таблиці й формули.
- Режим редагування статичних розділів: Головна, Арматура, Таблиці, Формули. Редагуються тексти та комірки таблиць; зміни зберігаються у локальному сховищі застосунку.
- Друк поточного розділу через системну службу друку Android (зокрема збереження у PDF).
- Два окремі каталоги фото: «Креслення» та «Фото виробів». Для запису можна змінити назву й примітки, відкрити або видалити фото.
- Експорт резервної копії JSON та відновлення з неї. Копія містить відредаговані сторінки й фотоархів.

## Збірка APK
Потрібні JDK 17 та Android SDK (platforms;android-35, build-tools;35.0.0). У корені проєкту:

```bash
gradle --no-daemon assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`.

Або запусти workflow **Build Budivelnyk UA APK** у GitHub Actions.

## Важливо
Проєктний архів перевірено на цілісність ZIP та синтаксис JavaScript. APK у цьому середовищі не збирався й робота на фізичному телефоні не підтверджена. Перед використанням на об'єкті перевіряй розрахунки; довідник не замінює проєкт конструктора.
